# げんつき、ちょっと待った

原付の調子がおかしい時に、原因は当てずに「走っていいかの目安」と「店に見せるメモ」を返す、Claude 用の文章ファイル一式。

安全装置は 2 つ。分からない所を嘘で埋めない（本人が言っていない時刻や場面を足さない・原因を当てない）。乗ったらいけない時は止める（迷う時は「乗る前に店に電話」）。

作ったのは Claude。判断の基準を口で話して作らせたのは僕——原付で通勤する会社員、副業で配達、非エンジニア、整備士ではありません。

通勤の足が止まると困る人ほど、調子がおかしくても無理に乗ってしまいます。整備の知識が無いと「このまま走っていいのか、止めた方がいいのか」が分かりません。聞ける人がいなければ、そのまま乗って帰ります。

このフォルダの文章ファイル（Markdown）を Claude に読ませておくと、不調をふつうの言葉で書くだけで、まず次を返します。

- **今乗っていいかの目安**: 🔴 今すぐ店に電話・乗らない ／ 🟡 乗る前に店に電話・乗るかは店に聞く ／ 🟢 急がない・次に店に行く時に
- **電話の前に見ること**（使い方の間違いで直る物だけ。例: キルスイッチ、ギアが N）
- **電話する先の順**と、**電話で言う一言**

落ち着いたら 3 つだけ答えると、線の下に**店に見せる症状のメモ**が付きます。原因・部品・金額は書きません。動かすのに要るコードはありません（確かめるための試験 `tests/run.sh` はあります）。

## こういう時に

- 朝エンジンがかからない。どこに電話して、何て言えばいいか分からない時に
- 走っていて調子がおかしい。このまま乗って帰っていいのか、自分では決められない時に
- 検索すると「原因は〇〇」と断定する記事が多くて、自分の症状と照らし合わせられない時に

## 置く前／置いた後（同じ入力・同じモデル・各 1 回・無編集）

入力: 「走り出しがもっさりして、坂で前より遅い」

**置く前**（何も置かない Claude Code・全文は `examples/01_before_after_same_input.md`）

> 原付（スクーター）で「走り出しが重い」「坂で前より遅い」は、多くの場合、**部品の消耗**が原因です。
> （中略）
> ## よくある原因（多い順）

**置いた後**（このフォルダを置いた Claude Code・1 回目・無編集）

> 🟡 乗る前に店に電話。乗るかは店に聞く。
>
> いつもの店 → 近くのバイク屋 → ロードサービス（入っていれば）
> アクセルを何度もふかさない
>
> 電話で伝えること
> 「走り出しがもっさりして、坂で前より遅いです。」
>
> 落ち着いたら、3 つ教えてください。お店に渡すメモを作ります。
> 1. 車種は？（ナンバー（数字の板）の色も）
> 2. いつから？（例: 先週）
> 3. いつもと違う音はしますか？（例: しない）
>
> 色は AI の目安です。迷ったら店に聞いてください。

置く前は原因を多い順に並べ、置いた後は原因を出さず、今どうするかを先に出します。どちらが正しいかではなく、知識の無い人が次に何をするかが決まる形かどうかの違いです。

ほかの実物:
- `examples/02_supercub_neutral_solved.md` — 「エンジンはかかるのに進まない」→ 電話の前に見ることで、ギアが N だったと分かって直った。見つかったランプ切れは 🟢。
- `examples/03_crosscub_noise_yellow_to_red.md` — 「走れるけど変な音」で 🟡 → 答え（さっきから・走行中ずっと・ガラガラ）で 🔴 に変わった。
- `examples/10_cases_20261105/` — 10 通りの入口と、1 回目の出力（下の表）。

## 使い方

**最初に 1 回だけ（2 分）**: `my_bike.md`（claude.ai なら指示の一番上の【あなたのバイク】）に、車種・ナンバーの色・いつもの店の名前と電話番号・ロードサービスの電話番号を書いておきます。非常用の連絡メモと同じで、困ってからでは書けないので。空でも動きますが、書いておくと車種を聞かれず、電話先の番号までそのまま出ます。

**A. Claude Code**: このフォルダを開いて、症状をふつうの言葉で送るだけ。

**B. claude.ai の Project（スマホのアプリ・ブラウザ）**: Project を 1 つ作り、「指示」欄に `project_paste.md`（全部を 1 枚につなげた物・約 4,700 字・空白込み）を貼る。無料プランでも Project は作れます（上限 5 つ・2026-11-05 時点の料金ページとヘルプ記事）。

紙を印刷したい時は、ブラウザの印刷で。

## 色の線（1 本の問い）

「いけるやろ」と思っている人に、外野の友達が「それはやめといた方がええんちゃう？ 店に聞いてみ」と言う一言、のつもりで決めています。

| | 例 | 色 |
|---|---|---|
| 危ない症状・もう動けない・急に出て続く音や振動 | ブレーキ・ガソリンの匂い・煙・ハンドルのふらつき・空気が抜けたタイヤ・赤いランプ・かからない・進まない | 🔴 今すぐ店に電話。乗らない（煙・火花・ガソリンの時は先に「バイクから離れて・火や煙なら 119」） |
| 危なくないとは言い切れない | 変な音とだけ・前からの音・もっさり・オレンジのランプ・釘が刺さっているが空気はまだ | 🟡 乗る前に店に電話。乗るかは店に聞く |
| 走れて、怪我の側でなく、前から変わらない | 直った後に見つかったメーターのランプ切れ など | 🟢 急がない。次に店に行く時に |

赤は 3 つ（危ない症状・もう動けない・急に出て続く音や振動）だけに絞っています。何でも赤にすると「またか」で効かなくなるからです。赤ではない可能性がある時は 🟡「乗る前に店に電話」で、乗るかどうかを自分で決めず、店に聞く順にしています。

自分で確かめる時は、Claude Code が入った端末でこのフォルダを開いて:

```bash
bash tests/run.sh
```

`tests/cases.tsv` の 10 本を 1 回目だけ順に回し、出た色と期待する色を並べて「合う／合わん」を表にします（2026-11-05 深夜に回した結果: 10 / 10 合う）。決まりを直すたびに、これで崩れていないかを見てきました。動かすのに要るのは文章だけで、コードはこの試験と `make_paste.py`（貼り付け用の 1 枚を作る補助）だけです。

## やらない事と、その理由

- **原因を当てない・部品と金額を書かない**: 知識の無い人は AI の答えが合っているか確かめられません。部品代だけ先に知って店に行くと、工賃や開けてから出てくる部品で揉める種になります（作った人が車の受付側に 10 年いた時の実感）。メモの各行には出どころの札（`[本人]` `[本人の推測]` `[AI 知識・店で確認]` など 5 つ）を付けて、店が 1 行ずつ確かめられるようにしています。
- **「電話の前に見ること」は原因の判定ではない**: 使い方の間違い（キルスイッチ、ギアが N、スタンド、ガソリン）で直る物を、止まったまま 1 動作で確かめるだけ。直らなければ電話。危ない症状の時は出しません。
- **乗っていいかを決めない**: 🔴 は「乗らない」と書きますが、🟡 は「乗るかは店に聞く」です。最後に決めるのは本人と店。
- **ふだんのメンテ（オイル交換の時期など）には入らない**: それは店が見てくれています。この係は困った時だけ。
- **店を選ばない**: 電話先は「いつもの店 → 近くのバイク屋 → ロードサービス」の順だけ。

## 作りの芯: AI に埋めさせない

AI は、分からない所をもっともらしく埋めます。相談の場面では、それが一番の困りごとでした。試している間に、実際に次の埋めが出ました（どれも本人は言っていない）:

- 「さっきから（2026-11-05 夕方ごろ）」の「夕方ごろ」
- 電話の一言に足された「さっきから」
- 「どんな時に起きるか: 発進しようとした時」
- AI が案内した確かめを「本人がやった事」に書いた（「スタンドの確認を案内済み」）

これを、決まりの文で 1 つずつ止めました（時刻・場面・場所は本人の言葉のまま／君が足してよい日付は作成日だけ／案内した事を本人がやった事に書かない、など）。原因を当てないのも、メモの各行に出どころを付けるのも、同じ理由です。知識の無い人は、AI が埋めた所と本人が言った所を見分けられないので。

## 道具を足さなかった理由（Skills・MCP・フック・サブエージェントを使っていません）

- 地図の MCP（最寄りの店）: 店を選ぶ責任がメモに乗る。いつもの店を先に書いておく形にした。
- 危険を判定するフック: 「乗ると怪我するか」は言い方の揺れが大きく、語のリストより文で書いた方が外さないと判断した（比べ試しはしていません）。
- 部品表を引くスキル: 作った人自身は自分の車種の部品表を読ませて、原因を推測で相談し、部品代の概算まで出す使い方をしています。公開にあたって読者を整備の知識が無い人まで広げるために、意図して外しました（整備を自分でする人向けの版は `advanced/` に旧版として残しています・未完成）。

読み込むのは文章ファイル 4 枚（`CLAUDE.md`・`core/shin.md`・`core/sheet.md`・`hats/genki_nishu.md`）と `my_bike.md` です（`hats/_TEMPLATE.md` は別の現場用の雛形）。同じモデルに同じ入力を渡して、文章があるかないかで返ってくる物の形が変わりました（上の「置く前／置いた後」）。

## 似た物（2026-11-04 に調べた範囲）

- 四輪: 症状をチャットで聞いて、原因候補・緊急度・修理費の目安と整備工場向けの要約を出すアプリ（2026-11-04 の調べで見つけた物・名前は README には書きません＝後から読者がたどれる出典を残せなかったため）。いちばん近い。
- バイク: 症状から原因と修理手順を案内するアプリがいくつかある（FixioMoto https://apps.apple.com/us/app/id6756850715 など）。
- メーカーの相談窓口・JAF・保険のロードサービス＝来て動く／販売店へ案内する型。

この 4 つ（原因を当てない・電話の前に使い方の間違いだけ確かめる・電話する先と一言まで出す・メモの各行に出どころを付ける）を一度にやる物は、調べた範囲では見当たりませんでした。調べ切ったとは言えません。使い方の間違いを先に確かめる所は、取扱説明書の「故障かな？と思ったら」と同じ発想です。

## どう作ったか

1. 作った人が、自分で直した／店に出した実例を口で話した（10 月末）。
2. 文章ファイルに書いて動かし、事情を知らない Claude に点検させ、反例を探す点検をかけ、直すたびに同じ入力でやり直した（記録は `examples/_audit_log.md`）。
3. 2026-11-05 の夜、作った人がスマホとデスクトップの claude.ai で実際に何十回も打って試した。そこで「分からないが並ぶメモは店が見ても使えない」「緊急時は長い文を読めない」「電話の前に試せる事が電話の後に来ている」「車種を答える前にギアの話が出る」などが出て、形を作り直した。60 代で知識の無い人の役を別の Claude に演じさせて、止まる言葉も探した（AI の推測なので本物の代わりではありません）。
4. 決まりを足し続けて 16,000 字まで膨らみ、足した決まりが効かなくなったので、約 4,700 字に書き直した。書き直した版で 10 通りを試した（上の表）。

## 限界（2026-11-05 時点）

- 色・電話の前に見ること・排気量の行は AI の一般知識による目安で、外れることもあります（例: 車種によってはギアが入っていてもエンジンがかかる、など）。直らなければそのまま電話、で締めてあります。
- 赤は 3 つ（危ない症状・もう動けない・急に出て続く音や振動）では厳しめに出ます（ブレーキが鳴るだけでも 🔴）。迷う時は 🟡「乗る前に店に電話」です。
- 試したのは Opus 5.5（Claude Code と claude.ai）・2026-11-05。同じ入力でも回ごとに言い回しや確かめの数は揺れます。版が変わると中身も変わります。
- 対象は市区町村ナンバーの原付（一種・二種）。126cc 以上や車でも色と止まる症状は出しますが、メモの中身は浅くなります。
- 写真はメーターだけ（ランプのマークが分からない時）。写真で試したのは 0 回です。
- 普通のチャットに毎回「原因を決めずに、今乗っていいかと電話の一言を出して」と頼めば、近い物は出ると思います。このファイルは、その頼み方と止まる線を毎回同じにしておく物です。

## English (5 lines)

A set of Markdown files for Claude (Claude Code or a claude.ai Project) that helps a person with no mechanical knowledge when their moped (scooter) acts up. Without guessing the cause, it first returns a traffic-light answer — red: don't ride, call the shop now / yellow: call the shop before riding and ask whether to ride / green: no rush — plus one-step checks for common user mistakes (kill switch, neutral gear), who to call in order, and one sentence to say on the phone. After three calm questions it adds a symptom note for the shop, with each line tagged by its source, and never names parts or prices. The rule for the colors is one question: can a novice rule out injury and getting stranded if they keep riding? Built and tested by a non-engineer commuter during Built with Claude: Japan 2026.
