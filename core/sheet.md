# 1 枚の型（店に渡す症状のメモ・A5 1 枚・印刷かスクショ）

## 入口（本人が書く欄・分かる所だけ・話し言葉でよい）

- 車種と、ナンバーの色（白／黄／ピンク）:
- いつから:
- どんな時に（走り出し・信号待ち・雨の日・坂・加速中 など）:
- どんな症状（音・匂い・振動・警告灯・かからん など）:
- 自分でやった事・最近いじった所（社外パーツ含む）:
- 今の走行距離／前回のオイル交換（距離か時期）／前回のタイヤ交換:

## 出力（係が全文から作り直す・この順・この見出し）

```
# 店に渡す症状のメモ（作成日 YYYY-MM-DD）
（安全に関わる語が出た時だけ、ここに 1 行:）乗らずに店へ（またはロードサービス）

## 車両
- 車種／ナンバーの色／走行距離 … 各行に札

## 症状の時系列
1. いつ・どの状況・何が … [札]（確認のしかた: …）
2. …

## 本人がやった事
- … [本人の申告]

## 本人が今できる確認（5 分・店に行く前）
- … （例: 音をスマホで録る → 紙に「録音あり」）

## 店で見てもらう所の候補（原因やない・見る順の提案）
- … [AI の推測] / [AI の知識・店で確認]
- この車種でよくある例: … （帽子に出典がある時だけ・1 行・[] つき）

## 仕分け（帽子の主ならこうする・万人向けやない）
- 今日自分で／工具を足せば自分で／店へ／直さん（売る・買い替え・機能を諦めて乗る）のどれか 1 つ＋理由 3 行以内
- 乗れん日数の見積り: … [AI の推測]
- 次に一番安く白黒つく手: … 1 つ

## メンテの目安
- 前回のオイル／タイヤと、取扱説明書の指定の比較 … [本人の申告]＋[取説で確認]

## 分からん所
- 係が分からん・線の外と判断した所をそのまま書く

## 未回答
- 聞いたが答えの無かった問い … [本人 未回答]
```

- 札の無い行は書かん。
- 「診断」の語を使わん。部品・商品・店を推さん。
- 全部で A5 1 枚（目安 40 行）に収める。長くなるなら時系列を残して他を削る。
