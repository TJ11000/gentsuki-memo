# 実例 00 — 「前」: この md を置かない素の Claude Code（Opus 5.5・`claude -p --setting-sources project`・空のフォルダ・2026-11-05・1 本目・差し替えなし）

実例 01（5 本目）と同じ入力。比較のための計測で、係の出力やない。無編集。11/3 の 1 本目（入口の文が旧版＝「半年前から・異音」）は git の履歴に。

## 入口

クロスカブ110（JA45）、ピンクナンバー。先月くらいから、セルボタン押したら「ガキッ」て感じの音がして、それからセルがいつもと違う音でちゃんと回らんようになった。キックならかかる。走行は45,000kmくらい。あと、買った直後からクラッチ側で「ガチャガチャ」「カタカタ」ってバタついた音がすることがあって（いつもじゃない）、走れるから放置してた。

## 素の出力（無編集）

セルの症状は**スターター系の機械的なトラブル**の可能性が高いです。クラッチ側の音は別件の可能性が高いですが、こちらも一度見ておいたほうがいいです。

## 1. セルの「ガキッ」→ 回らない

キックでかかるなら、エンジン本体は元気です。モーターの力をクランクに伝える部分が怪しいです。

**候補（多い順）**
1. **スタータークラッチ（ワンウェイクラッチ）の摩耗・破損**
   - 4.5万kmなら摩耗していてもおかしくない部品です。
   - 典型的な症状は、セルを押すと「キュイーン」とモーターだけが空回りする、または「ガキッ」と噛んで滑ることです。
2. **スターターのリダクションギア（減速ギア）の歯欠け**
   - 「ガキッ」の後にずっと「ガリガリ」「ジャー」系の音がするなら、こちらの可能性もあります。
3. **バッテリー弱り**
   - 電圧が足りないと圧縮で押し返され（ケッチン気味）、その衝撃でスタータークラッチを傷めることがあります。
   - 「ガキッ」の原因がバッテリーで、壊れたのがクラッチ、というパターンもあります。

**自分でできる切り分け**
- バッテリー電圧を測る。エンジン停止で12.5V以上、セルを回している最中に9.5Vを大きく割らないかを確認します。
- セルを押したときの音を聞き分ける。
  - 「ウィーン」と軽く空回り → スタータークラッチ
  - 「ガリガリ」「ガチャ」と引っかかる → ギア
  - 「ウッ…ウッ…」と重く遅い → バッテリーかモーター

**当面の扱い**
- 原因がはっきりするまで、**セルは使わずキック始動にしてください**。空回りや歯欠けのまま使うと、金属片が出たり、ほかのギアまで傷めたりして修理代が上がります。
- 修理は左のカバーを開けて、フライホイール（専用プーラーが必要）を外す作業です。部品代はそれほど高くないことが多いですが、工具と手間がかかるので、慣れていなければショップに任せるのが無難です。

## 2. クラッチ側の「ガチャガチャ」「カタカタ」

**まず確認したいこと**
- **エンジンオイルの量と状態**。量が足りないか劣化していると、クラッチ周りもバルブ周りも音が出やすくなります。いつ交換したかも含めて確認してください。
- **クラッチ調整**。カブは右カバーにクラッチ調整ネジがあり、ずれていると異音や変速のギクシャクが出ます。中古で買ったなら一度も調整していないこともあります。
- **鳴るタイミング**。どれに当てはまるかで当たりがつけやすくなります。
  - アイドリング中か、走行中か
  - 冷えているときか、温まってからか
  - **シフトペダルを踏んでいる間に音が消える／変わるか**。変わるならクラッチ周り（遠心クラッチやアウターのガタ）の可能性が高いです。

「走れるから放置」で済むこともありますが、悪化すると高くつきやすい場所です。セルを見てもらうついでに、「クラッチ側の音も聞いてほしい」と伝えて一緒に見てもらうのが効率的だと思います。

## ショップに持ち込むとき
上に書いた「どんな音か」「いつ鳴るか」をメモして伝えると、診断が早く安く済みやすいです。セルを押したときの音と、クラッチ側の異音はスマホで動画を撮っておくのがおすすめです。あわせて、車体番号でホンダのリコール対象になっていないかも確認しておくといいです。

音の様子（空回りっぽいか、引っかかる感じか）や、異音が出るタイミングがわかれば、もう少し絞れます。
