# 置く前／置いた後（同じ入力・同じモデル Opus 5.5・2026-11-05・各 1 回・無編集）

## 入力
走り出しがもっさりして、坂で前より遅い

## A. 何も置かない Claude Code（空のフォルダ）
原付（スクーター）で「走り出しが重い」「坂で前より遅い」は、多くの場合、**部品の消耗**が原因です。乗り方が悪いわけではないので、心配しすぎなくて大丈夫です。

## よくある原因（多い順）

1. **駆動ベルトとウエイトローラーのすり減り**
   エンジンの力を後ろのタイヤに伝える部品です。すり減ると力がうまく伝わらず、まさに「出だしがもっさり」「坂で遅い」状態になります。走行距離が1万〜2万kmを超えていて一度も交換していなければ、これが一番怪しいです。
2. **エアクリーナー（空気を取り込むフィルター）の詰まり**
   息苦しい状態になり、パワーが落ちます。
3. **点火プラグの劣化**
   加速が鈍くなったり、エンジンのかかりが悪くなったりします。
4. **タイヤの空気圧が低い**
   見落とされがちですが、走りがかなり重くなります。
5. **ブレーキの引きずり**
   ブレーキが軽く効いたままになっている状態です。

## 自分でできるチェック

- **タイヤを指で押してみる**: 柔らかいと感じたら、ガソリンスタンドで空気を入れてもらいましょう（無料のところが多いです）。一番手軽で、これだけで改善することもあります。
- **押して歩いてみる**: エンジンを切って押したときに前より重い、またはブレーキを離してもスーッと進まないなら、ブレーキの引きずりかもしれません。
- **メーターの走行距離を見る**: お店に相談するときに必ず役立ちます。
- **寒い朝だけ症状が出るか**: 冬はエンジンが温まるまで重く感じることがあります。1〜2分ほど暖機して改善するなら、大きな問題ではないことが多いです。

## お店に持っていくとき

バイク屋さんで次のように伝えれば十分通じます。

> 「出だしが重くて、坂で前より遅くなった。走行距離は○○km。ベルトやプラグを見てほしい」

だいたいの費用の目安です（車種やお店で変わります）。
- ベルトとウエイトローラーの交換: 1万〜2万円前後
- 点火プラグの交換: 2千〜3千円前後
- エアクリーナーの交換: 2千〜4千円前後

**次のような症状があれば、早めにお店で見てもらってください。**
- 「キュルキュル」「ガラガラ」など、前はなかった音がする
- 焦げたような臭いがする
- アクセルを回しても空回りしているような感じがする

ベルトは切れると走れなくなるので、通勤中に止まってしまわないよう、近いうちに点検してもらうと安心です。

もしよければ、**走行距離**と**最後に点検や部品交換をした時期**を教えてください。もっと原因を絞り込めます。
