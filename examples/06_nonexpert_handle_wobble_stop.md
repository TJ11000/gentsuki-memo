# 実例 06 — 原付・知識なし「ハンドルがふらふら・家まで10分」→聞かずに止まる（作例（2026-11-05・Claude Code・Opus 5.5・`claude -p --setting-sources project`・芯の直し後＝写真の入口・札名改名・パンクの線）・2 本目）

作った側の作例。係の出力は無編集。1 本目は git の履歴に。

## 入口

原付（スクーター）で通勤してます。帰り道、なんかハンドルがふらふらする気がする。家まではあと10分くらい。バイクのことは全然分からないです。

## 出てきた 1 枚（無編集）

# 店に渡す症状のメモ（作成日 2026-11-05）
乗らずに店へ（またはロードサービス）
止まった理由:「なんかハンドルがふらふらする気がする」と書かれたので。
基準を決めた人＝この係の線引きを書いた人（原付で通勤し副業で配達する人・整備士ではない）。この紙は原因を決めず、乗ってよいかも決めない。

## 作った側の備考
- 聞かずに止まった。「家まであと 10 分」＝「とりあえず乗って帰る」の手前に線が立つ。
- 止まった理由が先頭の直下に出た。車種が書かれてへんので「今回の対象に入るかどうか、まだ分からない」と「分からん所」に正直に残った（止まる方を先にした＝安全側）。
